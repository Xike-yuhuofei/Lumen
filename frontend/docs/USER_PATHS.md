# Lumen Web 前端 · 用户旅程清单

> 本文档梳理「用户打开 Lumen 后，抱着某个具体目的会走完的完整流程」，作为端到端（E2E）测试场景的编排依据。
> 每条旅程包含：**目标 → 起点 → 细链步骤（含每步 UI 交互）→ 终点/预期结果**，并附关键异常/分支。
> 依据均为 `frontend/src/app/` 下的真实实现（`App.tsx`、`pages.tsx`、`SettingsModal.tsx`、`sessions.ts`、`mock/data.ts`、`api/*.ts`）。

## 范围与边界

- 仅覆盖 Web 前端（不涉及 CLI / SDK / Cron / WS API 入口本身）。
- 仅做流程梳理，不落地测试代码。
- 允许真实调用外部模型（`GITEE_API_KEY` 等凭据）。
- 覆盖主线旅程、边缘旅程、异常/分支三类。

## 0. 入口与初始状态

- 打开 Lumen 即直接进入主界面，**前端无登录/认证门**（账户在侧栏底部为写死的 `Xike / Free`）。
- 顶部模式切换标签 `Work / Code / Design`（默认 `Code`），三者切换侧栏导航项与首页内容。
- Hash 路由：`#/new`（新建/首页）、`#/chat/:sessionId`（对话）、`#/spaces`（学习空间）、`#/marketplace`（插件市场）、`#/library`（资料库）、`#/files`（我的文件，仅 Work）、`#/design-system`（设计系统，仅 Design）。
- 侧栏（Code 模式）导航：`新建对话(⌘⌃N)`、`学习空间`、`插件市场`、`资料库`。
- 输入框（Composer）通用控件：能力选择（`对话`/`引导学习`）、`＋`添加文件及更多（上传图片/当前项目的文件/命令/插件/技能）、`调用插件`（头脑风暴/网页搜索/深度推理 + 管理插件/探索更多插件）、附件标签、发送/停止。`Enter` 发送、`Shift+Enter` 换行、`⌘/Ctrl+A` 全选。

# 一、主线旅程（goal-driven）

## J1 · 学习一份新资料（核心闭环）

**目标**：把一份外部资料变成可学习内容，并据此开启一段教学。

**起点**：侧栏点击「资料库」（`#/library`）。

**步骤**：
1. 进入「资料库」页，页面显示标题「资料库」与右上角「刷新」「导入资料」两个按钮。
2. 点击「导入资料」→ 弹出「导入资料」Modal，展示待上传文件列表与说明文字（首次导入将自动创建知识库 `library`）。
3. 点击「开始导入」→ Modal 进入「上传中 → 已上传，正在解析并建立索引」+ 进度条。
4. 观察进度条增长，轮询直到状态 `ready`（显示「导入完成」，N 个文件已成功解析并建立索引）。
5. 点击「完成」→ Modal 关闭，资料库列表刷新，新条目以卡片形式出现（类型图标/文件名/大小/所属知识库/状态「已解析」）。
6. 在新条目卡片上点「添加到学习空间」（按钮变「添加中…」→「已加入学习空间」）→ 底部 Toast 提示「已加入学习空间」。
7. （或）点击「打开」→ 「资料预览」弹窗展示解析出的文本正文，点「关闭」返回。
8. 切到「学习空间」（`#/spaces`）看到对应新空间卡片，点「继续学习」→ 进入 `#/chat`，发起 `mastery_path` 教学 turn，消息区流式返回 Lumen 的教学内容（诊断/讲解/提问等）。
9. 回复问题后，教学持续推进；可随时回到「学习空间」点开卡片查看进度（掌握度 %、模块/知识点、待复习）。

**终点**：资料被解析入库 → 关联学习空间 → 成功进入教学对话并产生练习/讲解交互。

**关键后端依赖**：`createKnowledgeBase` / `uploadFilesToKb`（导入）→ `getKbInfo`（轮询）→ `createLearningGoal`（加入空间）→ WS `start_turn`（mastery_path）。

**异常分支**：见 X1（后端未启动）、X4（导入解析失败）、X5（学习空间加载失败）。

---

## J2 · 直接开启一个学习目标

**目标**：为某个主题/目标制定学习计划并立即开始教学。

**起点**：侧栏点击「学习空间」（`#/spaces`）。

**步骤**：
1. 「学习空间」页显示已有空间卡片列表（或空态「还没有学习空间」）。
2. 点击右上角「新建空间」→ 弹出「新建空间」Modal。
3. 在「空间名称」输入框填标题（如「掌握线性代数第三章」），在「想学什么（可选）」填描述。
4. 点击「创建空间」（空名称时按钮禁用）→ Modal 关闭 → 自动发起一段 Learn 教学 turn，跳到 `#/chat`。
5. 消息区流式返回 Lumen 的教学内容，侧栏出现新会话；教学按摸底诊断→讲解→练习等阶段推进。
6. 后续每次进入「学习空间」点「继续学习」即可接续。

**终点**：新学习空间创建成功并进入教学对话闭环。

**后端依赖**：`createLearningGoal` → WS `start_turn`（mastery_path）。

**异常分支**：见 X5、X7（创建失败）。

---

## J3 · 普通对话问答

**目标**：就某个问题获取 Lumen 的回答（不涉及学习闭环）。

**起点**：打开 Lumen（默认 `#/new` 首页）或点「新建对话」。

**步骤**：
1. 首页显示欢迎语「Learn with Lumen」、输入框与能力卡片（应用开发/项目理解/游戏创意/工具脚本）。
2. 点击输入框（可先点能力卡片填充提示），输入问题。
3. （可选）点「调用插件」按钮 → 在「可用插件」里勾选 `头脑风暴`/`网页搜索`/`深度推理`；点「＋」→「上传图片」选择图片作为附件。
4. 按 `Enter`（或点发送）→ 创建新会话、切到 `#/chat`，消息区流式展示回复，期间顶部显示会话标题与时间。
5. 回复完成后可继续追问（同会话累加）。

**终点**：用户问题得到流式回答。

**后端依赖**：WS `start_turn`（capability=`chat`，可选 `tools`/`attachments`）。

**异常分支**：见 X1、X6（超时）、X8（发送失败提示）。

---

## J4 · 继续已有学习（回到空间接续）

**目标**：回到之前的学习空间，从当前进度继续学。

**起点**：侧栏「学习空间」（`#/spaces`）。

**步骤**：
1. 列表中找到目标空间卡片（显示阶段标签、掌握度 %、知识点数）。
2. 点卡片「继续学习」→ 携带该书 `book_id` 发起 `mastery_path` turn，进入 `#/chat`。
3. （或）点卡片主体（非按钮区域）→ 打开「进度详情」弹窗（整体进度、下一步动作、模块/知识点状态、待复习数）→ 弹窗底部「继续学习」。

**终点**：从既有进度继续教学。

**后端依赖**：`getLearningProgressMap`（详情）、WS `start_turn`（mastery_path）。

**异常分支**：见 X5、X6。

---

## J5 · 探索并安装/更新插件

**目标**：发现一个能扩展 Lumen 能力的新插件并安装（或更新既有插件）。

**起点**：侧栏「插件市场」（`#/marketplace`）。

**步骤**：
1. 「插件市场」页按能力分类（教学与学习/资料处理/搜索与研究/工具与自动化/集成）分组展示插件卡片。
2. 点顶部分类 tab 或辅助筛选（全部/官方/已安装/可更新），或在搜索框输入关键字过滤。
3. 在卡片右侧按钮看到 `安装`（未安装）/`更新`（已安装且有更新）/`打开`（已安装）。
4. 点「安装」→ 按钮切换为「打开」，该插件进入「已安装」态（本地状态）。
5. 点卡片主体 → 打开「插件详情」弹窗（描述 + 可用技能 + `＋安装技能`）。
6. 「可更新」筛选下点某插件「更新」→ 状态刷新。

**终点**：完成一次插件发现→安装/更新（本地状态切换）。

**后端依赖**：当前 `plugins` 为前端静态数据（`mock/data.ts`），安装态为本地 `installedPlugins` 状态。**注意**：无真实后端写入。

---

## J6 · 配置个人环境（主题/语言/工具）

**目标**：按偏好调整界面主题、语言、回复语言、超时、可选工具等。

**起点**：侧栏底部账户卡片，或账户菜单「设置」。

**步骤（细链，二选一入口）**：
1. 点击侧栏底部账户（`Xike` / `Free`）→ 弹出账户菜单。
2. （主题快捷）在菜单项「主题」右侧子菜单中点「暗色 / 亮色 / 跟随系统」→ 界面即时切换并持久化。
3. （完整设置）点菜单项「设置」→ 打开「设置」弹窗。
4. 「通用」页：主题（亮/暗/跟随系统）、语言（简体中文/English）、本地链接打开方式（始终询问/内置浏览器/系统浏览器）、产物路径（点「更改」编辑路径）。
5. 切到「对话与工具」页：回复语言（中文/英文）、等待超时（下拉选 30/60/180/300/600/1800 秒）、可选工具开关（头脑风暴/网页搜索/深度推理）。
6. 关闭弹窗（点遮罩/Esc/关闭按钮）。

**终点**：偏好设置生效并持久化（部分同步到后端）。

**后端依赖**：`/api/v1/settings/ui`（主题/语言）、`/api/v1/settings/chat-response-timeout`（超时）、`/api/v1/settings/enabled-tools`（工具）。

# 二、边缘旅程（edge）

## E1 · 删除资料
侧栏「资料库」→ 在某条目点「删除」→ 弹「删除资料」确认框 → 点「删除」→ 条目从列表移除 + Toast「已删除」。**取消分支**：点「取消」/遮罩/Esc → 不删除。

## E2 · 插件更新
「插件市场」→ 辅助筛选切到「可更新」→ 出现带「更新」按钮的已安装插件 → 点「更新」→ 状态刷新（本地）。

## E3 · 退出登录
侧栏账户菜单 → 点「退出登录」→ **当前为占位按钮，无真实登录态与跳转**（仅 UI 存在）。

## E4 · 重命名 / 删除学习空间
「学习空间」→ 卡片「更多」菜单 → 点「重命名」弹框改名保存；点「删除」将该空间移除并刷新列表。

## E5 · 重命名 / 置顶 / 删除会话
侧栏历史会话悬停「更多」→ 置顶/取消置顶、重命名、删除；删除后本地与后端会话均移除，并自动切到下一个会话或 `#/new`。

## E6 · 资料预览打开/关闭
「资料库」→ 条目「打开」→ 预览弹窗展示正文 → 点「关闭」/遮罩/Esc 关闭。

## E7 · 占位页访问
Work 模式下侧栏「我的文件」（`#/files`）与 Design 模式下「设计系统」（`#/design-system`）→ 显示占位标题页（无真实数据）。

# 三、异常与分支（exception / branch）

## X1 · 后端未启动（连接失败）
任一对话发送（或加载会话）时后端不可用 → 消息区/提示出现 `无法连接 Lumen 后端，请确认本地 API 已启动。`（前端 `STREAM_CONNECT_ERROR`）。

## X2 · 资料解析失败 → 重新解析
导入或在库资料解析为 `error` → 条目状态显示「解析失败」并附错误摘要 → 点「重新解析」→ 触发重新排队并轮询，成功后恢复「已解析」，失败则保持错误态。

## X3 · 资料库加载失败
「资料库」进入时后端异常 → 显示错误文案 + 「重试」按钮 → 点重试重新拉取。

## X4 · 导入解析失败
导入 Modal 处理中解析为 `error` → 进入「导入失败」阶段显示错误 → 底部提供「关闭」/「重试」→ 重试重新上传解析。

## X5 · 学习空间加载失败
「学习空间」进入时后端异常 → 显示 `无法加载学习空间，请确认后端已启动`。

## X6 · 对话等待超时
回复超过设定超时时间仍无事件 → 前端 `failTurnIdle`，本轮以错误块结束，提示「等待回复超时，请稍后重试或在设置中延长等待时间」，可发 `cancel_turn`。

## X7 · 创建学习空间失败
「新建空间」提交失败 → 显示 `创建空间失败，请重试`。

## X8 · 发送失败提示（无活跃连接）
发送时 WebSocket 未就绪 → 本地会话创建侧栏提示 `会话创建失败，请重试` / `回复失败，请重试`。

## X9 · 删除资料确认分支
同 E1 的「取消」路径；删除接口失败 → Toast `删除失败`。
